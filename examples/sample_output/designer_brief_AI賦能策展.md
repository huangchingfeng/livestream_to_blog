# 阿峰老師部落格配圖設計指令

**文章標題**：一人策展 120 個品牌？阿峰老師的 AI 工具箱大公開

---

## 圖一：封面圖 (1200 x 630 px)

### 給人類設計師的中文指令

**設計概念**：「一人軍團」- 展現一人運用 AI 工具完成龐大專案的魄力與效率

**視覺構成**：
- **主視覺**：一位專業人士站在中央，周圍環繞 120 個品牌 logo 的抽象光點或六邊形網格，形成「指揮中心」的感覺
- **背景**：深藍漸層底色（#1E3A5F → #2563EB），帶有微妙的數位網格或電路線條紋理
- **裝飾元素**：流動的光線軌跡連接各個節點，象徵 AI 工具串連工作流程

**配色運用**：
- 主背景：科技藍漸層
- 重點強調：智慧紫光暈效果
- 點綴：活力橘作為視覺焦點（如「120」數字）

**文字配置**：
- 主標題：「一人策展 120 個品牌？」（大字、置中偏上）
- 副標題：「阿峰老師的 AI 工具箱大公開」（中字、主標下方）
- 品牌標識：右下角放置「阿峰老師」logo 或文字

**字體建議**：
- 主標題：思源黑體 Bold，字級 48-56px
- 副標題：思源黑體 Regular，字級 24-28px

**注意事項**：
1. 留意社群平台會裁切邊緣，重要元素置中
2. 「120」這個數字要特別醒目，建議用活力橘
3. 整體要有「一人撐起一切」的氣勢但不壓迫
4. 避免過於冰冷的科技感，加入柔和的光暈增添溫度

## 圖二：重點摘要圖 (1080 x 1080 px)

### 給人類設計師的中文指令

**設計概念**：「AI 工具流程圖」- 以工作流程串連六大工具，呈現完整的專案執行路徑

**視覺構成**：
- **版面結構**：上方標題區 + 中央六宮格/流程圖 + 下方品牌標識
- **主視覺**：六個工具以卡片或圖標形式呈現，用流程線條或箭頭串連
- **背景**：淺色漸層（白→淺藍灰），保持閱讀清晰度

**六大工具呈現**：

| 順序 | 工具名稱 | 應用階段 | 建議圖標 |
|------|----------|----------|----------|
| 1 | Perplexity AI | 訪談前準備 | 搜尋/研究圖標 |
| 2 | NotebookLM | 錄音轉文字 | 麥克風→文字圖標 |
| 3 | Gemini Gems | 自動化內容產出 | 魔法寶石/自動化圖標 |
| 4 | N8N + Ideogram | 海報設計 | 設計/圖像圖標 |
| 5 | NotebookLM | 智慧媒合 | 連結/配對圖標 |
| 6 | Cursor + Claude Code | 網站開發 | 程式碼/網站圖標 |

**配色運用**：
- 背景：淺灰藍漸層（#F8FAFC → #E0E7FF）
- 工具卡片：白色卡片 + 各工具對應色彩邊框
- 流程線條：智慧紫 (#7C3AED)
- 數字標籤：科技藍 (#2563EB)

**文字配置**：
- 頂部標題：「阿峰老師的 AI 工具箱」
- 副標題：「一人策展 120 品牌的秘密武器」
- 各工具名稱 + 應用說明（簡短 4-6 字）

**字體建議**：
- 標題：思源黑體 Bold，32-36px
- 工具名稱：思源黑體 Medium，18-20px
- 應用說明：思源黑體 Regular，14-16px

**注意事項**：
1. 資訊層次要清晰，避免過於擁擠
2. 每個工具卡片大小一致，視覺整齊
3. 流程順序要一目了然（可用數字 1-6 標示）
4. 預留足夠呼吸空間，不要塞太滿
5. NotebookLM 出現兩次，用不同圖標區分用途

## 圖三：金句卡 (1080 x 1080 px)

### 給人類設計師的中文指令

**設計概念**：「攀登高度」- 用視覺隱喻呈現「創意力 + 執行力 = 更高成就」

**視覺構成**：
- **主視覺選項 A**：抽象的上升階梯/山峰剪影，人物站在頂端
- **主視覺選項 B**：向上飛升的光線軌跡，從底部匯聚向上
- **主視覺選項 C**：簡潔的幾何構成，用線條表達「高度」意象
- **背景**：深色漸層（科技藍→智慧紫），營造沉穩大器感

**金句排版**：
```
「創意力跟執行力
　會決定你使用 AI 的高度」

                    —— 阿峰老師
```

**配色運用**：
- 背景：科技藍→智慧紫漸層（#2563EB → #7C3AED）
- 金句文字：純白色 (#FFFFFF)
- 關鍵字強調：「創意力」「執行力」「高度」可用活力橘 (#F97316) 或成功綠 (#10B981) 點綴
- 裝飾元素：淡金色或淺紫色光暈

**文字配置**：
- 金句：置中，佔畫面主要視覺
- 署名：右下角，「—— 阿峰老師」
- 可加入品牌小 logo 於角落

**字體建議**：
- 金句：思源黑體 Bold，36-42px
- 關鍵字可加粗或放大 10-15%
- 署名：思源黑體 Regular，18-20px

**注意事項**：
1. 金句是主角，裝飾元素不要喧賓奪主
2. 文字要有足夠對比度，確保清晰可讀
3. 整體氛圍要勵志但不雞湯、專業但有溫度
4. 建議加入微妙的光暈或漸層效果增加質感
5. 可加入輕微的引號裝飾符號「」增添設計感
