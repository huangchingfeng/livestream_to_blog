## 圖一：封面圖 (1200 x 630 px)

### 給人類設計師的中文指令

**用途**：文章封面、社群分享預覽圖（OG Image）

**視覺概念**：
展現「人與 AI 協作」的畫面，強調 AI 是工具、人是主角。避免冰冷的純科技感，要有「效率提升後的從容感」。

**構圖建議**：
- 左側 1/3：放置主標題文字區塊
- 右側 2/3：主視覺圖像區
- 底部可加入微妙的漸層色帶，增加品牌感

**必要元素**：
1. 主標題：「AI 效率革命」（大字、醒目）
2. 副標題：「從每天節省 2.5 小時開始」（較小字）
3. 視覺元素：一位專業人士自信地使用筆電/平板，周圍環繞著代表 AI 的光點或數位元素
4. 強調數字：「2.5 小時」可用特殊顏色或外框強調

**配色執行**：
- 背景：深藍到紫的漸層 (#1E3A8A → #5B21B6)
- 文字：白色主標題，淺藍色副標題
- 光效：藍紫色的柔和光暈點綴

**注意事項**：
- 文字需留安全邊距（左右各 60px），避免社群裁切
- 確保文字在縮圖狀態下仍可辨識
- 避免過於抽象的 AI 意象（如機器人臉），選擇工具性的呈現
- 人物表情應該是「從容、掌控」而非「忙碌、焦慮」

## 圖二：重點摘要圖 (1080 x 1080 px)

### 給人類設計師的中文指令

**用途**：Instagram 貼文、文章內重點整理

**視覺概念**：
資訊圖表風格，清晰呈現五大重點。設計需兼顧「一眼掃過能抓住重點」與「細看有完整資訊」。

**構圖建議**：
- 上方 20%：標題區「AI 工具效率指南」
- 中間 60%：五個重點的卡片式排列（2+2+1 或環形排列）
- 下方 20%：來源標註 + CTA

**必要呈現的五大重點**：

| 重點 | 建議圖示 | 顏色建議 |
|------|----------|----------|
| ChatGPT 適合寫作 | 鋼筆/文件圖示 | 綠色系 (#10B981) |
| Claude 適合分析 | 放大鏡/圖表圖示 | 橘色系 (#F97316) |
| Midjourney 適合圖像 | 畫筆/圖片圖示 | 紫色系 (#8B5CF6) |
| Prompt 三原則 | 三條橫線/清單圖示 | 藍色系 (#3B82F6) |
| 效率提升 3 倍 | 向上箭頭/火箭圖示 | 紅橘色系 (#EF4444) |

**設計細節**：
- 每個重點使用圓角矩形卡片承載
- 卡片有微陰影，營造層次感
- 圖示統一風格（建議 outline style 或 filled style 擇一）
- 「效率提升 3 倍」可設計得最大或最醒目，作為視覺終點

**配色執行**：
- 背景：淺灰或米白 (#F8FAFC 或 #FFFBF5)
- 卡片：白色底，彩色左邊條或圖示
- 標題：深灰 (#1E293B)

**注意事項**：
- Instagram 會顯示為圓形頭貼預覽，確認四角無重要資訊
- 字級層次要明確：標題 > 重點名稱 > 說明文字
- 預留品牌 Logo 或帳號名稱位置
- 資訊密度適中，不要塞太滿

## 圖三：金句卡 (1080 x 1080 px)

### 給人類設計師的中文指令

**用途**：社群分享、限動轉發、金句傳播

**金句內容**：
> 「AI 不是來取代你的，而是來放大你的能力的。」

**視覺概念**：
金句卡需要「一秒打動人」。設計重點是讓金句本身成為絕對主角，背景和裝飾都是輔助。傳達「empowerment 賦能」的正向力量。

**構圖建議**：
- 垂直置中的文字排版
- 上下各留 15-20% 呼吸空間
- 可將「取代」與「放大」做視覺對比處理

**文字排版建議**：
```
AI 不是來取代你的，
而是來放大你的能力的。
```
- 「取代」：可用刪除線或較淡顏色
- 「放大」：加粗、放大、或使用強調色

**視覺元素**：
- 背景：漸層色彩（藍紫漸層）或純色
- 可加入微妙的光暈效果在「放大」二字周圍
- 左右可有極簡的裝飾線條或引號符號「」
- 底部小字標註來源：講師 Kevin / 文章出處

**配色方案（建議採用）**：

| 項目 | 顏色 |
|------|------|
| 背景 | 深藍漸層 |
| 文字 | 白色 |
| 強調色 | 亮紫色 (#A78BFA) |

**注意事項**：
- 金句文字必須絕對清晰可讀，這是最高優先級
- 避免過度裝飾干擾閱讀
- 字體選擇要有「力量感」但不壓迫
- 引號要使用中文引號「」而非英文引號 " "
